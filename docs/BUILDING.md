# Building

## Toolchain

- Visual Studio 2026 (v18, MSVC 14.51) or any toolchain new enough for C++23
- [xmake](https://xmake.io) 2.9.0 or newer
- Windows SDK with the D3D11/D3D12 headers

xmake must run inside a Visual Studio developer environment. From Git Bash it
otherwise mis-detects mingw, so either run it from a `vcvars64` shell or force
the platform:

```
xmake f -p windows -a x64
xmake build SkyrimUpscaler
```

## Dependencies

`lib/commonlibsse-ng` is a submodule — clone with `--recurse-submodules`, or run
`git submodule update --init --recursive` afterwards. CommonLibSSE-NG resolves
SE and AE addresses through Address Library, so one DLL covers both runtimes.
VR support is disabled in `xmake.lua`.

The following are **not** vendored and must be placed under `extern/` yourself:

| Path | Source |
| --- | --- |
| `extern/Streamline/include` | [NVIDIA-RTX/Streamline](https://github.com/NVIDIA-RTX/Streamline) 2.13 headers |
| `extern/Streamline/external/ngx-sdk/include` | NGX SDK headers, shipped inside the Streamline repo |
| `extern/FidelityFX-SDK/Kits/FidelityFX` | [AMD FidelityFX SDK](https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK) 2.2.0 |

One patch is needed to the Streamline headers: `sl_pcl.h` has a
`#if __cplusplus == 202302L` branch containing an invalid
`using to_underlying = std::to_underlying;`. Force the portable fallback.

xmake resolves `directxtk`, `directx-headers`, `magic_enum` and `simpleini`
automatically.

## Targets

| Target | Output | Purpose |
| --- | --- | --- |
| `SkyrimUpscaler` | `SkyrimUpscaler.dll` | the plugin |
| `NeuralColorGrade` | `NeuralColorGrade.dll` | reference external neural module |
| `SkyrimUpscalerProbe` | `SkyrimUpscalerProbe.dll` | standalone diagnostic; dumps the render-target layout |

`SKSEPlugin_Version` and `SKSEPlugin_Query` are generated by the
`commonlibsse-ng.plugin` xmake rule. Do not hand-define them.

## Deploying a build

Copy `build/windows/x64/releasedbg/SkyrimUpscaler.dll` into
`Data/SKSE/Plugins/`. Under Mod Organizer 2 that is the mod's own folder rather
than the game directory. The Streamline and FidelityFX runtimes only need to be
placed once.
